# Component extraction matrix

Status: proposals, not an implementation plan approval. See [repository pins](../../research/REPOSITORY_PINS.json) for all full SHAs, runtimes and license hashes; every source link below includes its exact SHA. Source files are relative to each repository's root. No source extraction has occurred.

## Classification contract

- **REUSE**: retain/adapt a bounded existing artifact or module with attribution; state owners and integration boundaries still need definition.
- **PORT**: translate a bounded algorithm/contract into Rust, retaining attribution where implementation expression or fixtures are adapted; verify behavior instead of assuming parity.
- **REWRITE**: implement a focused product-specific equivalent; upstream is comparative evidence, not code to lift.
- **EXTERNAL TOOL**: invoke a separately installed official executable/service over a documented boundary; do not embed its authentication or engine.
- **DISCARD**: omit from this product scope. This says nothing about the upstream project's general quality.

A PORT is justified only for a small, understood semantic boundary. TS/Python service wrappers around PostgreSQL, Redis and Kubernetes are not cheap Rust extraction targets. Cost judgments are relative engineering assessments, not measured estimates.

## Port-versus-rewrite acceptance rule

Before copying code later: identify exact file/commit, bound dependencies, preserve licenses, list semantic tests, and estimate integration plus maintenance cost against a fresh narrow implementation. For C01/C03/C08, PORT means preserving selected semantics, not promising a byte-for-byte translation. A simple standard graph algorithm may be implemented independently; do not assert that a translation has no attribution obligations. No component receives a blanket reliability or security endorsement.

Remaining prerequisites: official-CLI release compatibility, native login checks without inference, device feasibility, Figma entitlements and binary/transitive notices. These belong to the approved prototype stage, not to this audit's completed static checks.
