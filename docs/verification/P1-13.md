## Implementation

- Domain `ipc`: strict bounded UTF-8 JSONL envelope parsing, canonical encoding, fragmented-frame decoder, event projection cursor and client close-proof state. Acknowledgement, operation readiness and observed helper exit are separate facts.
- Helper `--serve`: singleton/epoch startup, recovery inspection with admission closed, session/protocol handshake, typed command/query routing, receipt correlation, separate bounded control/query/output queues and control priority. Stdout is protocol only.
- Commands use the existing close/cancel/approval authority. HumanDecision requires exact displayed-review fields and revision; agent output has no approval route. Unknown commands, stale epochs, changed duplicate payloads and incompatible protocol mutations fail closed.
- Bounded SQL snapshot/event projections and normalized log/detail chunk queries. Snapshot pages bind a committed cursor; a concurrent commit invalidates later pages rather than mixing versions. Explicit partial-detail markers prevent treating clipped summaries as full review content.
- Helper worker registry runs existing P1-09 supervisors concurrently and settles through P1-10. Shutdown commits P1-12 all-target intents; the registry joins workers before finalization. A stalled worker retains ownership and cannot produce READY.
- EOF/broken transport initiates emergency handling without confirmation. If the durable shutdown intent cannot commit, an in-memory flag requests stop through each retained runner. The runner still owns all signals and absence checks. Writer failure retains durable ambiguity and claims; the fallback cannot create success evidence.
- ShutdownReady contains the committed P1-12 receipt. User-close exit 0 requires a bounded frame and successful write/flush acknowledgement after worker joins. Emergency handling emits no Ready and preserves an unclean session. Durable command/shutdown receipts remain queryable after restart.

The implementation contract, operation payloads, bounds and lifecycle details are in `docs/architecture/STDIO_PROTOCOL.md`. No authoritative acceptance criterion was edited. Runtime dependencies are unchanged. One test-only dependency on the existing `jojo-helper` workspace crate lets storage integration tests exercise the actual helper runtime; the allowlisted lock graph changed only for that edge.

## Invariants, exclusions and limitations

P1-09 remains the only process/signal authority; no IPC code signals by PID or adopts an orphan. P1-10 remains the result/claim/evidence authority. Stop requests, process exit alone, provider terminal prose, timeouts and worker joins alone never authorize successful shutdown. P1-11 startup remains paused and conservatively quarantines unresolved work. Failed persistence and unknown local writers never produce clean acknowledgement. Queued work and worktrees are retained; shutdown interruption is distinct from permanent task cancel. Network/credential isolation and pinned external dependencies remain unchanged.

Intentionally excluded: **P1-14 SwiftUI/AppKit quit flow**, GUI views, OS termination integration, arbitrary executable/argv IPC, scheduler dispatch orchestration, real providers/auth probes, remote effects, sockets/reconnect, stronger orphan containment, push/merge and Git initialization. Typed launch registration accepts already admitted frozen specs; the standalone protocol does not yet expose an application Start workflow.

Limits/risks:

- A permanently stalled worker retains the helper and ownership. After 45 seconds a failure is visible; it is not detached or converted into proof. OS force termination still needs P1-11 recovery.
- Saturated control/output queues, framing errors and transport failure trigger emergency handling. Bulk Busy/error delivery is best effort on a broken/saturated channel. No success is inferred from a missing response.
- A receipt may commit before a channel failure. This preserves durable recovery evidence but cannot prove that the GUI received it. A Ready frame with failed/unknown flush does not qualify for successful user-close exit.
- Snapshot pagination restarts on concurrent commits; sustained writes can require repeated reload. Normalized logs are paginated; partial summaries are explicitly marked. Full raw spools remain evidence rather than a protocol stdout stream.
- The domain client state is a transport contract tested against synthetic responses. Native Swift transport/view/OS-quit wiring remains P1-14.
- Process groups are not hostile-code containment; unrecorded escaped descendants can remain unknown. Same-user hostile tampering remains outside the existing immutability guarantees.

Token efficiency: reused the existing sandbox runner and shared attempt fixtures, used targeted/indexed source queries and focused development tests before the full final gate. No provider/model invocation occurred. Provider token counts and monetary savings are unavailable and are not estimated.
