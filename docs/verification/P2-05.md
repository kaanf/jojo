3. Model-run commands can read any user-readable file, including the Codex credential file, and can write to `/tmp` and `$TMPDIR`; Jojo's scope check sees only the worktree.
4. Jojo's recorded start time is UTC while the operator's `ps` shows local time.
5. One Rust test is intermittent.
6. Every P2-04.1 remaining risk other than risk 1 stands unchanged.
